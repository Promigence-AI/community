# Promigence community

This is where people who run AI agents on [Promigence](https://www.promigence.ai) ask questions, trade ideas and hear news from us. When you are stuck, start a [Q&A discussion](https://github.com/Promigence-AI/community/discussions/categories/q-a), and mark the answer that solved it so the next person finds it quickly. Ideas and rough edges belong in [Ideas](https://github.com/Promigence-AI/community/discussions/categories/ideas). Anything you built and want to show goes in [Show and tell](https://github.com/Promigence-AI/community/discussions/categories/show-and-tell), and our own news appears under [Announcements](https://github.com/Promigence-AI/community/discussions/categories/announcements).

Read first. The [docs](https://www.promigence.ai/docs) and the [guides](https://www.promigence.ai/docs/guides) answer most first questions, from installing the CLI to running a thousand sandboxes at once with a cap on what they can cost.

Some things never belong in a public thread. Report security issues privately, as [SECURITY.md](SECURITY.md) explains, and send questions about your account or your bill to support@promigence.ai. Please never paste API keys, secrets or private code into a discussion, even in a hurry.

Taking part means you agree to the [code of conduct](CODE_OF_CONDUCT.md).
