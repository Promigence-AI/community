# Security

Please report a security vulnerability privately, never in a public discussion.

The quickest way is the Report a vulnerability button on this repository's Security tab. You can also email support@promigence.ai with "security" in the subject line, and we will reply from there. Our [vulnerability disclosure policy](https://www.promigence.ai/legal/vulnerability-disclosure) sets out the rules and the safe harbor we give to good-faith research; read it before you test anything.
